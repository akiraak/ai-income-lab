# 前提条件の確定（自分のセグメントを選ぶ）

## 目的・背景

[shortlist.md](../../specs/income-taxonomy/shortlist.md) は個人の制約を決め打ちせず、資金・時間・回収期間の 3 軸でセグメント別に候補を提示している。
実験に入るには、このうち 1 セルを自分の制約として確定し、検証タスクの優先度を並べ替える必要がある。

2026-08-26 に確定した値:

| 軸 | 選択 |
| --- | --- |
| 初期投資に回せる元手 | **大（1,000 万円〜）** |
| 週あたり投下可能時間 | **週 5〜15 時間** |
| 許容できる回収期間 | **6 ヶ月〜1 年** |
| 既存スキル | ソフトウェア開発 |

## 対応方針

1. shortlist.md の「前提条件の明文化（未確定）」を確定値で埋める
2. 3 軸交差表のセル（大 × 週 5〜15 時間）は回収 1〜3 年前提で書かれており、第 3 軸（回収 6 ヶ月〜1 年）と合わない。
   各軸のテーブルを交差させて、このセグメント専用の候補リストを shortlist.md に新設する
3. TODO.md の検証タスクを候補リストの順に並べ替える。資金確定で解禁される I8・E1・E2 を追加する

## 影響範囲

- 更新: `docs/specs/income-taxonomy/shortlist.md`（前提条件の確定、セグメント別候補の新設）
- 更新: `TODO.md`（検証タスクの並べ替え）、`DONE.md`

## テスト方針

1. 候補リストの各件が、資金・時間・回収の 3 テーブルすべてに矛盾しないこと（外した件は理由を残す）
2. 人の関与度 L1〜L3 が候補に揃っていること（L1 だけに寄っていない）
3. 数値・判定はすべて既存の体系【推測】を引用し、新たな金額を断定しない
