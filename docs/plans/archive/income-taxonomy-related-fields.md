# 収入体系に接続する学問の調査

## 目的・背景

[docs/specs/income-taxonomy.md](../specs/income-taxonomy.md) は既存の学問を参照せずに一から組んだ。
このままでは「思いつきの体系」であり、どこが既存の知と一致し、どこが学問的に否定されているかが分からない。

体系の各層（仮説・分類軸・歴史軸・AI 差分・絞り込み）について、接続する学問分野と代表的な文献を対応付け、
**体系を補強する材料**と**体系に異議を唱える材料**の両方を洗い出す。

## 対応方針

1. 体系の層ごとに、対応する学問分野・概念・代表文献を表で対応付ける
2. 学問側から見て体系が食い違っている点を「異議」として別立てで列挙する
3. 異議のうち体系の修正に値するものを TODO 候補として起票する（修正そのものは本タスクの範囲外）
4. 数値・年代・著者名は記憶に頼らず、不確かなものは Web で確認する。確認できなかったものはその旨を明記する

## 影響範囲

- 新規: `docs/specs/income-taxonomy/related-fields.md`
- 更新: `docs/specs/income-taxonomy.md`（構成表にリンク追加）、`TODO.md`

## テスト方針（検証方針）

1. 体系の 5 層すべてに対応する学問が最低 1 つ付いているか
2. 「異議」が 3 件以上挙がっているか（補強だけなら調査の意味がない）
3. 文献は著者・年・題名まで書き、確認できなかったものにはその旨を付けているか
4. 図テスト: 学問と体系の対応関係を示す図が 1 枚以上あり、直前に主張の 1 行が付いているか
