# 管理画面を別の機械から見るための起動スクリプト

## 目的・背景

利用者の指示（2026-09-22）: **`ssh -N -L 3013:127.0.0.1:3012 titan` を実行する `run_xxxx.sh` を作る。接続アドレスも表示させる。**

きっかけは利用者の質問「titan の vibeboard は `http://titan-income-vibeboard/` から見えるが、管理画面は IP でアクセスできるか」。答えは **できない**（`AIL_BIND=127.0.0.1` ＝ titan のループバックにしか口を開けていない）で、CLAUDE.md が指定する見方が ssh のトンネルだったため、それを 1 コマンドにする。

⚠ **走らせるのは Sx360（titan ではない）**。titan 側は何も変えない。

## 対応方針

- 置き場: プロジェクト直下 `run-dashboard-tunnel.sh`（`run-server.sh` ／ `run-vibeboard.sh` ／ `run-sim.sh` ／ `run-live.sh` と同じ並び）
- 中身: `ssh -N -L <手元のポート>:127.0.0.1:<titan のポート> <ホスト>` を**前面で**走らせる（Ctrl+C で止まる）
- **接続アドレスを出す**（`http://127.0.0.1:3013/`）。⚠ トンネルが繋がってから出す ＝ 繋がる前に URL を出して「開けない」と言わせない
- 繋がったことの確かめ: 手元のポートが開くのを待ち、`curl` で HTTP の番号を見て ✅ ／ ⚠ を出す（`curl` が無ければ飛ばす）
- ポートの空け方は `run-server.sh` の作法に合わせる（⚠ **プロセスは名前ではなくポートから引く**・自分自身と親は殺さない）。⚠ **ただし自動で止めるのは ssh のトンネルだけ**にする（手元の機械の関係ないプロセスを殺さないため）

## 影響範囲

- 新しいファイル 1 つだけ。既存のコード・設定は 1 行も変えない
- titan 側の `AIL_BIND` ／ `AIL_AUTH_MODE` は変えない ＝ **面の規則（公開面は監視と停止だけ・操作はローカル面だけ）に触らない**
- ⚠ トンネル経由の接続は titan から見るとループバック ＝ **ローカル面**（監視 ＋ 記録 ＋ 判定 ＋ 停止・解除）が開く。これは CLAUDE.md が想定している見方そのもの

## テスト方針

titan 上では「Sx360 → titan」を再現できないので、**titan から titan 自身へトンネルを張って**確かめる（`--host localhost`）。

1. `./run-dashboard-tunnel.sh --host localhost --port 3013` → 接続アドレスが出て、`curl http://127.0.0.1:3013/` が 200
2. 同じポートでもう 1 度起動 → 古いトンネルを止めて張り直す
3. `--no-kill` で塞がったポート → 1 で終わる
4. `--host` が届かない名前 → ssh の失敗を読める形で出す
5. `-h` で使い方が出る

## 決めたこと

| 項目 | 既定 | 変え方 |
| --- | --- | --- |
| 手元のポート | 3013 | `--port N` |
| titan のポート | `dashboard/.env` の `AIL_PORT`（無ければ 3012） | `--remote-port N` |
| 繋ぎ先 | `titan` | `--host NAME` |
| ポートが塞がっていたら | ssh のトンネルなら止めて張り直す。⚠ ほかのプロセスなら止めずに終わる | `--no-kill` で常に終わる |
| 相手に繋がるまで待つ | 10 秒（ssh の `ConnectTimeout`。2026-09-25 に足した） | スクリプトの `CONNECT_TIMEOUT` |
| 手元のポートが開くまで待つ | 25 秒（⚠ 名前解決 ＋ `ConnectTimeout` より長くする ＝ ssh 自身に理由を言わせる） | スクリプトの `WAIT_S` |

## 追記（2026-09-25）: 繋がらないホストで居残るのを直した

- 形: ssh に接続の制限時間が無い（`connecttimeout none`）と、届かない相手には SYN の再送が尽きるまで約 127 秒居残る（9/22 の「2 分」）
- 直し: `-o ConnectTimeout=10` と、待つ上限 15 → 25 秒
- 【実測 titan】届かない IP（192.0.2.1）: 17 秒で打ち切り（理由なし）→ 10 秒で `Connection timed out`・rc=1 ／ 引けない名前: 0.3 秒・rc=1（変わらず）
