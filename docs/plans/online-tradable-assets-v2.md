# オンラインで売買できるものを、抜けが出ない手順で洗い直す（調査プラン）

起票: 2026-08-29 ／ [TODO.md](../../TODO.md)
前回: [online-tradable-assets.md](../specs/experiments/online-tradable-assets.md)（2026-08-28、母集団 22 件）

### なぜ「一覧を作り直す」ではだめか

前回の横断調査（[online-tradable-assets.md](../specs/experiments/online-tradable-assets.md)）は
母集団 22 件を洗って「新しい手法は 1 件も無い」と結論した。**これは調べた結果ではなく、探した場所の結果だった。**
母集団を自分の手法カタログの「資本」「資源」の行から拾ったため、出発点が最初から金融商品に寄っていた。

そのあと 2026-08-29 に 10 分野を追加したが、**追加した直後にまた抜けが見つかった**（商品・米）。

| 回 | 母集団 | 直後に見つかった抜け |
| --- | --- | --- |
| 2026-08-28 | 22 件 | 実物に板がある市場（スニーカー・カード・地金）、権利の常設市場 |
| 2026-08-29（1 回目） | ＋10 分野 | ⚠ **商品（コモディティ）が丸ごとゼロ**。貴金属以外の農産物・エネルギー・金属・畜産 |
| 2026-08-29（2 回目） | ＋商品 | ⚠ 米は農産物 ETF に入っておらず、受動保有の手段が先物しかない可能性 |

**3 回連続で抜けたなら、4 回目も抜ける。** 思いつきで列挙する限りこれは止まらない。
だから今回のタスクは「もっと多く挙げる」ではなく、**抜けたことに自分で気づける手順を作って回すこと**とする。

---

### Step 1: 6 つの独立した切り口で列挙する

**互いに盲点が重ならない切り口を使う。** 1 つの切り口で漏れたものが、別の切り口で拾えるようにする。
下の表の「種」は着手前に思いついた例であって、これが全部ではない。**各切り口で機械的に最後まで数えること。**

- [ ] **切り口 A: 監督官庁から逆引きする**（誰かが規制しているものは、誰かが売買している）
  | 官庁 | 拾えるもの（種） |
  | --- | --- |
  | SEC | 株・債券・投資信託・ETF・REIT・BDC・Reg A/CF の株式・仕組債 |
  | CFTC | 先物・先物オプション・スワップ・**イベント契約（予測市場）**・小売 FX |
  | FDIC / OCC | 預金・**ブローカード CD**・MMF |
  | 州の保険庁 | アニュイティ、⚠ **生命保険の買取（life settlement）** |
  | 州の不動産・徴税 | 不動産、⚠ **タックスリーエン（滞納税の公売）** |
  | FinCEN・州の送金業免許 | 暗号資産・ステーブルコイン |
  | **規制なし** | 収集品・実物・ドメイン・⚠ **IPv4 アドレス**・炭素クレジット |

- [ ] **切り口 B: 米国の税務書類から逆引きする**（⚠ **これが最も漏れにくい**。政府が把握している所得の型は様式で全部列挙されている）
  | 様式 | そこに現れる資産 |
  | --- | --- |
  | 1099-INT | 預金・債券・CD・MMF・国債 |
  | 1099-DIV | 株・ファンド・REIT（適格／非適格の別も） |
  | 1099-OID | 割引債・ゼロクーポン債 |
  | 1099-B | 売却したもの全般（株・債券・商品・暗号資産） |
  | 1099-MISC Box 2 | ⚠ **ロイヤリティ** — 印税・鉱区・特許・音楽 |
  | 1099-PATR | 協同組合からの配当 |
  | Schedule K-1 | ⚠ **パートナーシップ** — MLP・商品ファンド・不動産 LP・プライベートファンド |
  | Form 6781（セクション 1256） | 規制先物・外国通貨契約・指数オプション |
  | Schedule E | ロイヤリティ・賃貸・パススルー |
  | Form 4797 | 事業用資産の売却 |
  - [ ] 様式を 1 つずつ当たり、**そこに載る所得の型で、まだ母集団に無いものを拾う**

- [ ] **切り口 C: 証券会社の取扱商品一覧を全部見る**（⚠ 自分で思いつかなくても、向こうが並べてくれている）
  - [ ] Interactive Brokers の商品一覧（最も広い。株・ETF・債券・先物・先物オプション・株式オプション・FX・**金属現物**・投資信託・仕組商品・暗号資産）
  - [ ] Fidelity / Schwab の商品一覧（**ブローカード CD・MMF・貴金属**が個人向けに並んでいる）
  - [ ] TreasuryDirect の商品一覧（国債・TIPS・I Bonds・EE Bonds）

- [ ] **切り口 D: 機関投資家の資産クラス分類から**（個人に降りてきていない層も含めて数え、降りているか確認する）
  | 分類 | 種 |
  | --- | --- |
  | 公開市場 | 株式・債券・現金同等物 |
  | 実物資産 | 不動産・インフラ・**農地**・**林地**・商品・貴金属 |
  | オルタナティブ | PE・VC・ヘッジファンド・プライベートクレジット・不動産デット |
  | 保険連動 | ⚠ **カタストロフィボンド**・生命保険買取 |
  | 特殊 | ロイヤリティ・⚠ **訴訟ファイナンス**・リース（航空機・鉄道・コンテナ）・⚠ **炭素クレジット**・水利権 |
  | デジタル | 暗号資産・**トークン化された現物資産**・NFT・ドメイン・IPv4 |
  | 収集品 | 美術・ワイン・時計・カード・スニーカー・クラシックカー・楽器 |

- [ ] **切り口 E: 実在する取引所・マーケットプレイスを数える**（体系を見ずに、venue の側から）
  | 種類 | 種 |
  | --- | --- |
  | 証券取引所 | NYSE・Nasdaq・Cboe |
  | 商品・先物 | CME・ICE |
  | 暗号資産 | Coinbase ほか |
  | ⚠ 実物の板 | StockX（スニーカー）・TCGplayer（カード）・Chrono24（時計）・地金ディーラー |
  | ⚠ 権利の常設市場 | 音楽印税のオークション・特許の市場 |
  | ⚠ 未公開株の二次市場 | Forge・EquityZen |
  | ⚠ 債権の市場 | 住宅ローン債権・請求書ファクタリング |
  | 官公庁・清算 | 払い下げ・倉庫競売・返品在庫のロット |
  | 分割所有 | 美術・収集品・農地 |
  | ⚠ 変わり種 | クラウドの予約枠の転売・IPv4 アドレス・周波数・排出枠 |

- [ ] **切り口 F: 過去の見落としのパターンから、同じ形の抜けを探す**
  | # | やってしまった判断 | 実例 | 同じ形を探す |
  | --- | --- | --- | --- |
  | 1 | 「実物だから実地確認が要る」と決めつけた | スニーカー・カード・地金 | 他に実物で板があるものは |
  | 2 | **1 件を見て、型ごと落とした** | I Bonds 1 件で買取保証型全体 | 他に 1 件で切った型は |
  | 3 | **複数を 1 行にまとめて落とした** | 「サイト売買」に YouTube・ニュースレター・FBA を混ぜた | 他にまとめすぎた行は |
  | 4 | 体系に無いから探さなかった | 商品・トークン化 | 体系化した 2026-08-25 以降に生まれた市場は |
  | 5 | 「規約違反が多い」で調べずに終えた | ゲームアイテム・アカウント | 他に調べずに切ったものは |

### Step 2: 出尽くすまで回す

- [ ] Step 1 の 6 切り口を 1 巡したら、**新しく出たものを母集団に足して、もう 1 巡する**
- [ ] **2 巡続けて新規ゼロになるまで止めない**（1 巡で止めると「たまたま思いつかなかったもの」が残る）
- [ ] 各巡で「何件増えたか」を記録する。増え方が止まったことを数字で示せるようにする

### Step 3: 網羅性を点検する（⚠ ここを省略しない）

- [ ] 巡が終わったら、**「まだ見ていない切り口は無いか」を明示的に問う**
  - 見ていない官庁は／見ていない税務様式は／見ていない venue の種類は／使っていない言語圏の情報源は
- [ ] ⚠ **母集団に「規制なし」の層が何件あるか数える。** 前回はここがほぼゼロだった（規制がある＝見つけやすい、というバイアス）
- [ ] ⚠ **母集団に「金融商品でないもの」が何件あるか数える。** 前回はゼロだった

### Step 4: 4 ゲートを当てる（前回から流用。⚠ ただし運用を直す）

| # | ゲート | 判定基準 |
| --- | --- | --- |
| 1 | 入口 | 対面・実地確認なしで買えるか |
| 2 | 出口 | 常設の買い手がいるか（板があるか、運営・発行体が常時買い取るか） |
| 3 | 維持 | 保有中の作業が週 5 時間未満か（継続的な判断が要るものは労働に落ちる） |
| 4 | 受取 | 米国居住者（WA 州）が USD で受け取れるか。⚠ 連邦だけでなく**州で止まるものがある** |

- [ ] ⚠ **入口ゲートの運用を直す。** 「物か情報か」ではなく「**対面が要るか**」で判定する。前回はスニーカー・カード・地金を「実物だから」で落とした
- [ ] ⚠ **型で落とすときは、その型の代表を 3 件以上見る。** 前回は買取保証型を I Bonds 1 件で落とした
- [ ] ⚠ **落とすときも 1 行にまとめない。** 種類ごとに買い手の厚みが違う

### Step 5: 通過したものの一次情報を取る

- [ ] 利回りまたは値上がり率、保有コスト、最低単位、出口の型（板型／買取保証型）
- [ ] ⚠ **往復の売買コスト**（前回トークン化不動産はここで落ちた。往復 約 8%）
- [ ] ⚠ **課税区分**（適格配当／通常所得／collectibles 28%／連邦非課税／セクション 1256 の 60:40／⚠ K-1 が出るか）
- [ ] ⚠ **出口の厚み**（1 日の売買代金）。投入額 $100,000 が市場の何日分にあたるか

### Step 6: 現行の最上位と同じ土俵で比べる

比較の基準は**税引後の年間収入**（$100,000 を 1 年置いた場合）。所得階層は中位・上位の 2 ケース併記。

| 現行の最上位 | 中位 | 上位 |
| --- | ---: | ---: |
| 米国債 30 年 | $3,952 | $3,078 |
| 米国債 10 年 | $3,542 | $2,759 |
| 地方債 AAA 10 年 | $3,300 | **$3,300** |

- [ ] これを超えるものがあるか。無ければ「無かった」と書く

### Step 7: 体系に返す

- [ ] ⚠ **前回「新しい手法は 1 件も無い」と結論した原因が母集団の作り方だったことを記録する**
- [ ] 新しい手法が見つかったらカタログ（現在 64 件）へ追加する
- [ ] ⚠ **誤判定を直す。** 特に **D6「権利の買取」**（「二次流通が個別交渉」として落としたが常設市場が実在する疑い）と、
  **入口ゲートで落とした実物系**（不動産・太陽光・GPU 以外に巻き込んで落としたものが無いか）

### 前提（変わっていない）

税務上の居住地 **米国・ワシントン州シアトル** ／ 資金 **$100,000〜** ／ 週 **5〜15 時間** ／ 回収 **6 ヶ月〜1 年**。
実行（購入・口座開設・出品・登録）は行わない。一次情報と試算で採否を判定するところまで。
