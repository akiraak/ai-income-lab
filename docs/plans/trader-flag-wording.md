# トレーダーの「印」（停止 ／ 手じまい）を分かりやすい言葉に言い換える

2026-10-08。利用者の指示「トレーダーに印を付けるという表現があるけど、印が分かりにくいので別の表現にする」→「印についてプランを作成」。

## 0. 目的・背景

管理画面と CLI では、トレーダー 1 人ずつの「停止 ／ 手じまい」を **印** と呼んでいる（「この人の印」「印を立てた」「印を消す」・用語「人ごとの印（停止 ／ 手じまい）」）。2026-10-05 に作ったときの言葉で、「何をするものか」が言葉から分からない。

中身は「**執行器の次の回から、この人をどう動かすか**」の指定で、その場では何も売買しない。

この図の主張: 言い換えるのは人が読む文だけで、置き場・コードの名前・記録の形は変えない。

```mermaid
flowchart LR
  U["人: 管理画面 ／ control.py"] -- "停止 ／ 手じまい を書く<br/>（いまの言葉: 印）" --> F["control/&lt;人&gt;.json<br/>⚠ 名前は変えない"]
  F -- "次の回で読む" --> R["執行器 run_day.py"]
  R --> E["記録 events.jsonl<br/>⚠ trader_flag などは変えない"]
```

## 1. 言葉の案（⚠ 利用者が選ぶ）

| # | 言葉 | 画面の文の例 | よいところ | 気になるところ |
| ---: | --- | --- | --- | --- |
| A | **指示** | 「この人への指示」・「T4 に『停止』の指示を出した。売買が変わるのは執行器の次の回から」・「指示を取り消す」・「指示なし（普通に売買する）」 | 「人が執行器に頼む」ことがそのまま読める。停止 ／ 手じまいの両方に合う | 「合図」（モデルの提案）とは別の言葉だが、どちらも「何かをさせるもの」に読める |
| B | **予約** | 「この人の予約」・「T4 の『停止』を予約した。次の回から効く」・「予約を取り消す」・「予約なし」 | 「その場では何もしない・次の回で効く」が言葉に入っている | 手じまいが済んだ後も残る（「済み」が付いて以後は買わない）ので、「予約」が残り続けるのは少し変 |
| C | **運転の指定** | 「この人の運転」・「T4 を『停止』に切り替えた」・「指定を外す（普通の売買に戻す）」 | 名簿の「状態」（売買中 ／ 停止 ／ 手じまい）と並べて読める | 少し長い。「切り替えた」は「その場で変わった」と読まれやすい |

推す案: **A「指示」**（停止 ／ 手じまいのどちらにも合い、「その場では売買しない・次の回から」は今の文で添えたままにできる）。

## 2. 範囲

| 変える（人が読む文） | 変えない |
| --- | --- |
| 管理画面: トレーダーの詳細「この人の印」・名簿の面（列「いつから ／ 印」・確認のダイアログ・「再開（印を消す）」・説明の 1 行）・お知らせの帯（`main.py` の 4 文）・`lineup.py` の「印が無い」 | ファイル名と置き場 `control/<人>.json`・`control.py`・`/ops/traders/<人>/flag`・記録の `trader_flag`・`paused` ／ `liquidate`・コードの識別子（`flag`・`FLAG_KINDS` など）|
| 用語 `glossary.toml` の「人ごとの印（停止 ／ 手じまい）」（名前・短い説明・`where`）と、それを呼ぶ `info(...)` | ⚠ **別の意味の「印」**: 「本番の機械ではない」印（`NOT_PRODUCTION`）・「仮」の印（仮データ）・特性の「どこまで確かか」の印・試験用の人の印・`HALT` の「停止の印」 |
| 執行器の人が読む文: `control.py` の help ／ 表示・`run_day.py` の事象の `note`（「停止の印があるので…」など 3 つ） | 過去の記録・済んだプラン・`DONE.md` |
| 文書: `dashboard.md` §13-9・§13-10 の見出しと本文・`live-trading.md`・`howto-model-trader.md`・CLAUDE.md（言葉の表に 1 行足す） | |

⚠ 用語の名前を変えると `dashboard/tests/test_help.py` が落ちる（`info("…")` と `glossary.toml` を同時に直す）。⚠ `dashboard.md` の見出しを変えたら、`where` を grep で拾って直す（CLAUDE.md「説明の正本の分け方」）。

## 4. 影響範囲

- 管理画面の表示と、執行器が記録に書く `note` の文字だけ。売買・発注・記録の項目は変わらない（黄金の集計値は出来事の件数と注文の数なので変わらない）
- 本番に効くのはデプロイの後

## 5. テスト方針

- `./run-tests.sh`（執行器 → 管理画面 → selftest → mockrun）。`test_help.py`（用語とリンク）・`test_flags.py`・`test_roster.py`・`test_run_day_flags.py` の文字の照合を新しい言葉に
- 直した後に `grep -rn "印" dashboard/app experiments/live-trading/*.py` で、別の意味の「印」だけが残っていることを目で確かめる
