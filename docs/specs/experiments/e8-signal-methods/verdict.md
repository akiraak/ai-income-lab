### 7-2. ⚠ E8 は「打ち切り」ではなく「目標を年 1000% に置く限り成立しない」

| 問い | 答え |
| --- | --- |
| 年 1000% は達成できるか | ⚠ **できない。** 必要 SR 2.30（フルケリー）に対し、公表された最良は標本内・コスト前で 1.1〜1.7。**史上最高の 30 年記録（Medallion 年 63.3%）の 5.4 倍**を要求している |
| 届かない理由は「まだ探していない手法」か | ⚠ **違う。** 93 件を回して残ったのは A4・J1 の 2 件で、**両方ともモメンタム**。上限は手法ではなく **g ≤ SR²/2** と **Reg T の 2 倍** |
| では E8 は捨てるか | ⚠ **捨てない。** 段 3 の構成は税引後 **$22,000〜37,000/年**【推測】で、E1（$2,601）・E2（$3,542）を**期待値では上回る**（[online-tradable-assets.md §4](../../online-tradable-assets.md)） |
| ⚠ 上回るなら E1・E2 より良いのか | ⚠ **同じ土俵ではない。** E1・E2 の $2,601〜3,542 は**ほぼ確実な受取**、E8 の $22,000〜37,000 は**最大ドローダウン 30〜50% を伴う期待値**で、根拠も 強 対 中 である。⚠ **並べて比べられる数字ではない** |
| 段 1（現物だけ）ならどうか | ⚠ **年 8.7%【推測】＝ ほぼ市場平均。** 週 5〜15 時間を投じる理由が説明できない |

### 7-3. ⚠ 条件が変わったら、どこから見直すか

**カタログと失敗台帳は、判定が「届かない」でも残る。** 前提が変わったときに真っ先に見る場所を書いておく。

| 変わる前提 | 真っ先に見る場所 | 何が動くか |
| --- | --- | --- |
| **目標利回りを下げる**（例: 年 30%） | [§5-3](evidence.md) の達成率の表 | ⚠ **年 30% なら 段 3・SR 1.0・半ケリーで達成率 1.2 になる。** 目標が現実的なら判定は「成立」に変わる |
| 商品の段を 3 に開く | [§6-1](failures.md) の **R9** ／ [§1-7](frame.md) | A4・J1 が**片脚から両脚**になり、税も 24% → 18.6% |
| 板（L0）が手に入る | [§6-3](failures.md) の **X1 7 件** | H 系 8 件が一斉に再検査の対象になる。⚠ ただし往復 1,885 ms（X8）は残る |
| 会計情報を入力に入れる | [§1-1](frame.md) の線引き ／ [§4-1](evidence.md) | ⚠ **根拠が強の行が 4 件から大きく増える。** バリュー・クオリティ系が入る |
| 元手が 1 桁増える | [§6-3](failures.md) の **X4 = 0 件** | 容量が効き始める。Novy-Marx-Velikov の議論が当たるようになる |
| ⚠ FINRA の日中証拠金の移行が終わる（2027-10-20） | [§1-6](frame.md) | 日中証拠金不足の運用が固まる。**回転数の上限が再び現れる可能性** |

## 9. 方針との関係と、読むときの注意

| 方針 | 本書での扱い |
| --- | --- |
| 資金・機材を動かす実行はしない（2026-08-27） | **守った。** ⚠ **目標が年 1000% でも売買していない** |
| tastytrade の例外は **API の挙動**だけ（2026-09-05） | **守った。** [§2-1](data-routes.md) の Candle は**読み取り専用のプローブ**で、発注系には触れていない |
| 登録・契約・課金をしない | **守った。** Massive・Databento 等は【公表値】止まり |
| 数値は【実測】/【公表値】/【推測】を明示 | 各表に付けた。⚠ **カタログの粒度・回転数はすべて【推測】** |
| 投資助言ではなく調査資料 | ⚠ **特定の銘柄・売買を推奨していない。** 破産確率と前提（[§1-5](frame.md)）を判定と同じ節に併記した |

### 9-1. ⚠ この調査の限界

| # | 限界 |
| ---: | --- |
| 1 | ⚠ **自前のバックテストを 1 件も回していない。** 良い数字が出ても根拠にしない設計（[§5-1](evidence.md)）にしたので、**回さないことで失うものは無い**と判断した。⚠ ただし「悪い数字で落とす」側の反証も、その分だけ**公表論文に依存している**<br/>⚠ **2026-09-08 に部分的に埋めた** → [特徴量を見つけ出す手法の検証](../feature-discovery.md)。1 分足 63 銘柄と日足 32 年で特徴量の選別手法 11 件を回し、⚠ **すべてコスト後で負けた**（自前の検証も本書と同じ向きになった） |
| 2 | ⚠ **SR 1.1〜1.7 という「公表された最良」は標本内・コスト前の値**である。実運用の SR はこれより低いので、[§5-3](evidence.md) の達成率は**上振れの側に寄っている** |
| 3 | ⚠ **93 件は「探した範囲」であって「存在する全部」ではない。** 特に、公表されない実務の手法（執行の細部・会場ごとの癖）は入っていない |
| 4 | ⚠ **I3 の達成率を計算していない**（[§6-2](failures.md)）。実装できないと判断したが、⚠ **「計算しなかった」を「効かない」と読まないこと** |
| 5 | ⚠ **§1256 の 60/40 は「年内に決済する」前提で 18.6% としている。** 実際の税額は [trading-tax.md](../../trading-tax.md) の前提に従う |

### 9-2. 再現の仕方

```bash
cd experiments/tastytrade-api-sample
.venv/bin/python candle_probe.py                       # [§2-1](data-routes.md) の表（既定の 5 本）
.venv/bin/python candle_probe.py "SPY{=d}:12000" "SPY{=m}:730"
```

⚠ **相場データは本番（prod）の資格情報でしか出ない**ので `.env` の `TT_PROD_*` が要る。⚠ **期間の値 1 は書かない**（`{=m}` は取れるが `{=1m}` は 0 件）。
