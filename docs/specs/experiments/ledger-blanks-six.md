## 5. ⚠ 途中で踏んだ罠 — knockoff が本物のコピーになっていた

⚠ **最初の実装では、偽の列（knockoff）が本物と相関 0.98〜0.998 になっていた。**

| 確かめたこと | 実測 |
| --- | --- |
| 原因 | ⚠ **`E = default_rng(seed).normal(...)` で乱数を引いていた。** ⚠ **合成データも `default_rng(0)` で作ると、E が X とビット単位で同一になる** |
| 何が起きるか | ⚠ **偽物が本物のコピーになり、信号列では偽物のほうが先に Lasso に入る**（W = −0.75 と強い負）＝ ⚠ **枠が何も検出できない** |
| 実データでは | ⚠ **起きない**（実データは乱数列ではない）。⚠ **だがテストでは必ず踏む** |
| 直し方 | 種に形も混ぜた別の流れから引く（`SeedSequence([seed, n, p, 0x6B6E6F66])`） |
| 検査 | ⚠ **データの種と ctx の種をわざと同じにする回帰テストを足した**（対角の相関 < 0.3） |

⚠ **「動いているように見えるが何も検出していない」実装は、結果を見ても気づけない。** ⚠ **合成データで枠が働くことを先に確かめたから見つかった。**
